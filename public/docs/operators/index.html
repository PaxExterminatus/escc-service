Профиль клиента

Меню слева: Клиенты → Профиль.

  1. Введите ID клиента в поле «ID» вверху карточки и нажмите Enter (или кнопку «Search» на панели сверху) — карточка заполнится данными клиента.
  2. Данные клиента (ФИО, дата рождения, пол) отображаются для справки.
  3. В блоке «Контакты» можно поправить телефон и/или email прямо в полях.
  4. Переключатели рядом с телефоном и email — это согласие клиента на SMS / Email соответственно. Клик по переключателю сохраняет согласие сразу же, без отдельного нажатия «Сохранить».
  5. Если поменяли телефон или email — нажмите кнопку «Сохранить» на панели блока «Контакты», чтобы записать новые значения.
  6. Разверните панель «Отправка сообщений» ниже (клик по заголовку) — она подгрузит доступные каналы и шаблоны.
  7. Выберите канал (SMS или Email) переключателем сверху панели — под ним показан адрес получателя и есть согласие или нет.
  8. Опционально выберите шаблон в выпадающем списке — текст соберётся автоматически с реальными данными клиента (код клиента, сумма долга) и появится в поле ниже.
  9. Текст можно отредактировать вручную перед отправкой.
  10. Нажмите «Отправить» — кнопка недоступна, если у клиента нет согласия на выбранный канал или поле с текстом пустое.
  11. Разверните панель «Финансовая информация» ниже, чтобы посмотреть историю платежей/долга клиента.
  12. Иконка обновления (⟳) в заголовке каждой панели — принудительно перезагружает данные панели, не трогая остальную карточку.

Контейнер (посылка)

Меню слева: Клиенты → Контейнер.

  1. Введите ID контейнера и нажмите кнопку «Search» на панели сверху.
  2. Карточка покажет текущий статус посылки и доступные действия.
  3. Кнопки на карточке меняют статус контейнера (старт/стоп/установка конкретного статуса) — доступность зависит от текущего статуса.

Шаблоны сообщений

Меню слева: Рассылки → Шаблоны сообщений.

  1. Таблица показывает все шаблоны: код, название, текст, признак «Активен».
  2. Кнопка «Добавить» сверху справа открывает форму нового шаблона.
  3. В форме заполните код, название и текст. В тексте можно использовать плейсхолдеры вида {amount}, {client_code} — при отправке они подставляются реальными данными клиента.
  4. Флажок «Активен» — неактивные шаблоны не показываются оператору в панели отправки сообщений на странице профиля.
  5. Иконка карандаша в строке таблицы — редактировать шаблон; иконка корзины — удалить (с подтверждением).

Массовые рассылки — SMS на сегодня

Меню слева: Рассылки → Массовые рассылки.

  1. Таблица показывает очередь SMS-сообщений, готовых к сегодняшней рассылке.
  2. Кнопка «Обновить» — перечитать список из очереди заново.
  3. Ссылка «Скачать .txt» — выгрузить список в текстовый файл (для проверки перед отправкой).
  4. Кнопка «Отправить» — отправить всю очередь через SMS-шлюз. Кнопка недоступна, если список пуст. После отправки список обновится автоматически.
Бизнес-смысл этих операций (почему SMS шлётся именно так, что означают статусы контейнера) — в разделе «Руководства».
