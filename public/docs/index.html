escc-serviceДокументация

Три уровня документации — бизнес-логика легаси-схемы REVELATION (на которой построен escc-service) для трёх разных читателей, плюс техническая справка по самому API escc-service.

📋 Руководства

Для руководства: что делает система простыми словами, текущее состояние и главный риск для бизнеса — по каждой из восьми областей, без технических деталей.

💻 Для программистов

Полный технический разбор: PL/SQL-пакеты, таблицы, находки (хаки, мёртвый код, риски безопасности), схемы жизненных циклов.

🖱️ Для операторов

Короткие пошаговые инструкции по экранам escc-service — что где нажать, без бизнес-контекста.

🔌 API-справочник

Автогенерируемая OpenAPI-документация по эндпоинтам escc-service (Scramble).
Источник бизнес-логики: чтение DDL/PL/SQL схемы REVELATION (дамп 2026-09-04).
